IRSpectra-Bench · cross-vendor sweep

Recall is what separates models. Verification is not.

Ten model configurations, one blind protocol. Generation recall spans 0–53%; verification precision, wherever it could be measured, sits in a band of 62–84%. Verification beats generation for every vendor tested — the decomposition this paper rests on, reproduced outside the family it was measured in.

How the models compare

a, Generation recall on the 60-compound arm. Grey bars mark models below the formula-adherence floor — a model that cannot return a structure of the requested composition is not being measured on chemistry, so its recall is not ranked. b, The claim itself. Every point sits above the diagonal: verification precision exceeds generation recall for all four vendors carried through both stages. Claude, the model behind the paper's headline, is in orange.

Recall is the fraction whose true structure appears among the three ranked candidates. Verification precision is conditional on recall — how often forward-predicting each candidate's ¹³C and re-ranking selects the true one. Multi-candidate restricts that to compounds where more than one distinct structure was proposed, so the verifier actually had a choice to make.

What the table says

  • Three models beat the paper's headline model on recall, Grok by 21 points. That is the diagnosis working, not failing: recall is the movable factor, and a newer model generation moves it.
  • Claude's 84% precision was partly composition. Six of its nineteen recall-positive compounds carried a single candidate, so nothing was ranked and any verifier scores them by construction. The newer models almost never return singletons. Restricted to compounds where a choice existed, the four precisions land in a band — 77, 73, 67, 62 — and the apparent advantage largely dissolves.
  • Verification looks vendor-independent; generation does not. Precision spans 62–77% across four families while recall spans 32–53%. The wall is the generator, and the verifier is worth about the same wherever it is taken from.
  • Grok proposes the most candidates and ranks them worst (32 recall-positive, 62% precision). That is the paper's own precision-loss mechanism appearing between vendors rather than within one model.
  • Read formula adherence before recall. Nemotron's zero is not a chemistry result — only 2% of its candidates carried the requested composition. Composer and Luna fall below the floor too, which is why neither was carried through verification.

What these numbers are not

Only Claude's inequality is statistically separated. At n=60 the intervals for the three new models overlap their recall intervals, so those are directional rather than established tests.

These are models as served, not bare endpoints. They were reached through a coding-assistant harness that exposes reasoning-effort tiers — a decoding control the Claude arm never had. The tier used per arm was not recorded, and it should be.

Contamination was controlled for Grok only. Grok re-solved every batch from a clone with the answer files removed: 28/60 against 32/60, paired McNemar p=0.39, and four compounds were solved only in the arm that had no key — a model reading the key would solve a superset. Gemini and GPT-5.6 Sol rest on a weaker argument: on structures they got right whose reference carries assigned stereocentres, neither reproduced a single correct descriptor, which a key-reader would have copied.

The two arms are different compounds. The four Claude models of the lower block ran a 24-compound subset of the main round. Their ordering is informative; their numbers do not sit on the same axis as the block above.
