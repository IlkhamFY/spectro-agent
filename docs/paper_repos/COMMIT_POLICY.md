# Commit policy

1. **Author:** commits must be authored as the human account only
   (`Ilkham Yabbarov <ilkhamfy@gmail.com>` / GitHub `IlkhamFY`).
   No Cursor / Claude / bot committer identities.
2. **Messages:** nondescript release-style only, e.g.
   - `release v0.1`
   - `release manuscript`
   - `release figures`
   - `release data pointers`
3. **Branching:** single `main`. No `cursor/*` agent branches.
4. **Contents:** manuscript + figures + essential manifests/docs/scripts only.
